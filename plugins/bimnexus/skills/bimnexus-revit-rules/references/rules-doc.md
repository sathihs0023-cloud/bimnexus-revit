# Reporting

## Short final report with counts

End each task with a short report: what changed (counts), what was skipped and why, what needs manual review (ids), and what the user must do (sync, reload in other models). Offer a spreadsheet/Word record only if useful.

**Severity:** must

## Fixed tables stay fixed

When the user asks for a schedule/table with fixed rows (e.g. a door types table), build a manual table (header-section rows, element body filtered to zero rows), not an element-driven schedule, and match the formatting of the user's reference exactly.

**Severity:** must
