# New elements

## Revision cloud tags sit beside their cloud, no leader

Place every revision cloud tag directly beside its own cloud, about 200 mm clear of the cloud edge, with the leader turned off. Try the sides in this order: right (vertically centred), left, top, bottom, then the four corner-aligned side positions. Take the first position that does not overlap another tag or another cloud in the view. Read all tag sizes first and regenerate once, then set the head positions; do not regenerate inside the loop (PERF-003). Report any tag that could not be placed clear.

**Why:** Tags floating diagonally with leaders are hard to read in dense coordination plans; a tag right next to its cloud shows clearly which issue it belongs to.

**Severity:** must

## Elevator calculations: occupancy per DBC Table D.5 and round up group population

For every elevator calculation (Method 1 or Method 2), estimate population with DBC Table D.5 occupancy rates (Studio 1.5, 1BR 1.8, 2BR 3, 3BR 4, 4BR 5, +1 per extra bedroom or maid room), ask which units have a maid room, round each floor's group population up to the next whole person, and use actual floor-to-floor heights.

**Why:** User instruction: occupancy must follow the code from now on; fractions in Group 1/Group 2 columns rounded up.

**Severity:** must
